# Sample models

Only deterministic, generated `.3dm` fixtures belong in this directory.

Private student models and real submission files must stay under `samples/private/`, which is ignored by Git. Before v0.1 release, the integration tools will generate:

- `modelready-v0.1-fixture.3dm` — one controlled example for each rule
- `modelready-v0.1-benchmark.3dm` — 10,000 supported top-level objects
